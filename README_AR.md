# ميكا ١١ — ساحة النار المحلية (M11)

لعبة تصويب عربية ثنائية الأبعاد بأسلوب **بكسل آرت** للشبكة المحلية (LAN) —
تعمل **بلا إنترنت، وبلا حسابات، وبلا إعلانات**. مستوحاة روحيًا من متعة
«Mini Militia» و«Local Warfare» مع عمق «PUBG» (منطقة متقلّصة، غنائم، إحياء).

> **الحد الأدنى لأندرويد:** 8.0 (API 26) · **الهدف:** API 35 · **المعماريات:** arm64-v8a + armeabi-v7a

---

| المجلد | ماذا يحوي | حالته |


## ٢. الوصف الفني للأسلوب البصري

- **مقياس واحد ثابت:** 1 وحدة = 16 بكسل (`PPU = 16`) لكل الرسوم بلا استثناء.
- **الشخصيات:** 62 بكسل طولًا (ترتفع إلى 78 إطارًا كاملًا مع خوذة/جيت باك)،
  10 مشغلين (5 ذكور + 5 إناث) بهيكل (Rig) واحد مشترك ⇒ 1400+ إطار جاهز.
- **الأسلحة:** 28 سلاحًا، طول 40–70 بكسل، كل سلاح **مرسوم مسبقًا بـ13 زاوية**
  (0، ±15، ±30، ±45، ±60، ±90، 135، 180) — ممنوع التدوير الحر للبكسل.
- **لوحة ألوان واحدة:** 71 لونًا مُسمّى (`tools/m11lib/palette.py`)، والظلال
  والإضاءات محسوبة بنقل الصبغة (Hue Shifting) لا بتغيير السطوع فقط.
- **حد خارجي إلزامي:** 1 بكسل بلون `#0B0D10` حول كل عنصر.
- **رقش يدوي:** نمط باير 4×4 (Bayer) في التدرّجات والخلفيات.
- **الرسم الفائق ×4:** كل إطار يُرسم بـ4 أضعاف الدقة ثم يُختزل بـNearest —
  لا تنعيم ولا حواف مبكسلة عشوائيًا.

**قاعدة الأداء:** الدقة الداخلية ثابتة **640×360**، وتُكبَّر على الشاشة
بأعداد صحيحة فقط (`×2, ×3, ×4`) بلا أي فلترة ⇒ بكسل حاد على كل الأجهزة.

## ٣. الميزات الأساسية

### حركة تُشبه «ميني ميليشيا» وأفضل
جيت باك بوقود يتجدّد · قفزة مزدوجة · التصاق وتعلّق بالحواف · قفز من الحائط ·
انزلاق وتدحرج · انبطاح وزحف · سباحة · سلالم · ضرر سقوط · طرح وإحياء (DBNO 20 ثانية)
· قتل تأكيدي.

### قتال بعمق
28 سلاحًا بجداول إحصاءات كاملة (ضرر جسم/رأس، معدل، مخزن، إعادة تعبئة، **نمط ارتداد
مرسوم يدويًا لكل سلاح**، انتشار، سرعة طلقة، **اختراق جدران**، مدى فعّال، هبوط ضرر،
نُدرة، وزن) · 11 ملحقًا (نقطة حمراء/هولو/2×/4×/8×، كاتم، مخزن موسّع، مقبض أمامي،
ليزر، مخفّض ارتداد، قاعدة ثنائية) · دروع وخوذات وحقائب بثلاث درجات · إسقاطات جوية ·
غنائم بستّ درجات نُدرة · إحياء مرتبط بالحقيبة.

### 19 وضع لعب
معركة البقاء · الكل ضد الكل · فريق ضد فريق · زرع وتفجير · الاستيلاء على العلم ·
ملك التل · سباق الأسلحة · القنّاصة فقط · المشاجرة فقط · المسدسات فقط · العدوى ·
موجات البقاء · سباق التسلح · ساحة التدريب · غرفة مخصّصة · بطولة ·
**اغتيال الشخصية المهمة** · **الكرت الذهبي** · **المصعد** (الثلاثة الأخيرة من اختراعنا).

### 8 خرائط + محرّر
8 خرائط بتضاريس مولّدة إجرائيًا (بذرة موحّدة = خريطة متطابقة عند الجميع) بثلاثة
أحجام (6000×1400 للحرب الكبرى) و5 طبقات منظر خلفي متحرّك لكل خريطة · محرّر خرائط
داخلي يصدّر JSON مضغوطًا.

### شبكة محلية حقيقية
استضافة Listen-Server · 8 لاعبين + بوتات حتى 12 · اكتشاف ببثّ UDP على المنفذ 41980
(3 ثوانٍ) · إدخال IP يدويًا · دليل نقطة اتصال مصوّر · شاشة Network Overlay
(بِنج/تذبذب/فقد/حجم) · تنبؤ وتدحرج زمني 200 مللي ثانية · حجز مقعد 60 ثانية عند
الانقطاع · اقتراح ترحيل الاستضافة.

### بوتات بـ5 مستويات صعوبة
مشي وقفز واستخدام جيت باك لعبور العقبات · خط نظر حقيقي · وقت ردّ فعل (0.1 → 0.62
ثانية) · تصويب استباقي بخطأ قابل للضبط · مناورة جانبية · انسحاب ومعالجة ·
قنابل على التجمّعات · التقاط غنائم · إنعاش الأرفقاء.

### واجهة عربية كاملة RTL
لا نص محروق في أي صورة — كل النص يرسمه المحرك بخط **Cairo** مقلم (33 كيلوبايت/وزن)،
والأرقام لاتينية داخل اتجاه مستقل (قرار 13). 40 إنجازًا · تحديات يومية/أسبوعية ·
رتب 12 درجة · أشكال ألوان وأوسمة تُولَّد إجرائيًا · إعادات (Replays) بتسجيل الحالات.

## ٤. التحكم

| الفعل | لوحة المفاتيح/الفأرة | اللمس |
|---|---|---|
| الحركة | `W A S D` | عصا يسار |
| التصويب والإطلاق | الفأرة (يسار = إطلاق، يمين = تصويب) | عصا يمين |
| قفز | `Space` (اضغط مرتين = قفزة مزدوجة) | زر قفز |
| جيت باك | `W` أو `↑` (استمر بالضغط للطيران) | زر جيت باك |
| إعادة تعبئة | `R` | زر تعبئة |
| مشاجرة / قنبلة / علاج | `F` / `G` / `Q` | أزرار |
| انبطاح / انخفاض | `C` (انبطاح) / `Ctrl` (انخفاض) | أزرار |
| خريطة كبيرة / إحصاءات الشبكة | `M` / `N` (أو `F1`) | — |
| أوامر سريعة (Ping) | `V` ثم الأسهم + Enter | زر |
| جودة الرسم / الإضاءة | `F4` / `F2` / `F3` | الإعدادات |
| إيقاف مؤقت | `Esc` | زر |

**تخصيص كامل:** حجم وشفافية العصا والأزرار · عصا ثابتة/عائمة · تخطيط Claw
(2/3/4 أصابع) · يد يسرى · حساسية حركة وتصويب · جيروسكوب · إطلاق تلقائي ·
اهتزاز الجهاز.

## ٥. كيف يُبنى كل شيء؟

```bash
# 1) توليد كل الأصول (رسوم + صوت) — يستغرق ~75 ثانية
python3 tools/build_assets.py

# 2) توليد جداول Godot من نفس بيانات بايثون
python3 tools/gen_godot_data.py

# 3) تقليم الخطوط العربية (يعمل تلقائيًا داخل build_assets)
python3 tools/gen_fonts.py

# 4) تشغيل نسخة الويب
python3 tools/serve.py --port 8000

# 5) اختبار آلي بلا متصفح (480 إطارًا + لقطات PNG)
node tools/web_smoke.mjs
node tools/web_shot.mjs tdm 600 /tmp/frame
```
